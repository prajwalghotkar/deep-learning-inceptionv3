Project Overview
🏗️

Built From Scratch

Manually implemented the complete InceptionV3 architecture layer-by-layer using TensorFlow & Keras — from stem convolutions through all Inception blocks to the final classifier head.

⚡

22M+ Parameters

The model comprises 22,078,280 trainable parameters structured across Inception Block A, B, C variants and Reduction Blocks — faithfully replicating Google's original architecture.

🔬

Inception Modules

Implemented parallel convolutions (1×1, 3×3, 5×5) with concatenation, enabling the model to capture multi-scale features simultaneously — the core innovation of the architecture.

🌐

Real-World Deployment

Loaded Google's pre-trained ImageNet weights and validated predictions on real images — demonstrating end-to-end pipeline from architecture design to production inference.
